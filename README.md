# Jacobi-Eigenvalue-Algorithm-in-CPP
A C++ implementation of the Jacobi rotation method for calculating the eigenvalues of real symmetric matrices, written 3 years ago.

# The program includes:
• Symmetry validation for input matrices.
Iterative Jacobi rotations to diagonalize matrices.
• Random symmetric matrix generation for testing.
• Performance measurements with different convergence tolerances.
• Experiments with matrices of different sizes.

The project explores the relationship between numerical accuracy, matrix size, and algorithm execution time.
